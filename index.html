This is a first draft wired directly to your Sales / HR / Finance tools. Figures marked AUTO are pulled live — please sanity-check them against the source tools before this goes to OxeFit. Figures marked MANUAL are entered by you each week (see the relevant tab). See Data Health for exactly what loaded.

a Sales achieved vs. committed AUTO — sales tracker

FY-to-date and this-month, pulled from the weekly commit sheet. Achieved = max closed-won per rep across that month's weeks (avoids double-counting a snapshot repeated in several weeks); committed = sum of everyone's Commit value for the month. See Data Health for a note on when this can lag the tracker's live HubSpot refresh.

b Commitments for Delivering XS1 and XP1

Committed = unit forecasts reps enter on the weekly commit sheet for this month (forecastXS1 / forecastXP1), pulled from the sales tracker. Closed = actual units in the Delivery Tracker (the delivery CRM) that are past the OPEN stage — i.e. have left CoreV for the customer, whatever stage of onboarding they're at (Delivered - pending session, Delivered - installation pending, Postponed, or Closed) — one row per physical unit, so this is a confirmed count, not a forecast or a deal-level estimate.

Show every Delivery Tracker record behind this count (for auditing against the live tracker)

c Finance — cost vs. income (OxeFit)

Salaries = this month's "Due this month" total from HR's Monthly Salaries tab, not a flat sum of everyone's salary — a joiner or leaver only owes a prorated slice of the month (calendar days active ÷ days in month), and a joiner's one-time onboarding cost (visa + insurance) is added in their joining month only, matching HR exactly. Showroom rent and Warehouse rent are tracked separately below — each is agreed annually but due quarterly, so enter every quarter's due date + amount for the year up front (add a row per quarter); each one is automatically added to Total cost once it's within 30 days of its due date, and drops off once you tick "Paid" — no need to update anything by hand each quarter. Each property also has a one-time payment (from signing the lease) split into quarterly payment / security deposit / agent fees, which only counts toward a given month's cost if you tick "include" for it. Marketing budget still pulls from Finance's central cost pool. Income to OxeFit is AUTO — it's the same "Paid to OxeFit" figure from Finance's Payouts & OxeFit tab (every closed deal's mapped device cost × the milestone schedule × what's actually been collected from the customer so far), so it should match Finance exactly without retyping it here each week. The override field below is only for a week Finance hasn't synced yet — leave it blank to use the automatic figure.
